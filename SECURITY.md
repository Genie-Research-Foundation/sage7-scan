# Security policy

## Reporting a vulnerability in Sage 7 Scan

Please don't open a public issue. Email **support@sage7.dev** with "sage7-scan security" in the subject, a description, and steps to reproduce. You'll get an acknowledgement within 3 business days.

Use GitHub's private vulnerability reporting on this repository if you prefer.

## Scope

This policy covers the scanner, the GitHub Action and the npm package `@sage7/scan`. Vulnerabilities the scanner reports in *your* dependencies should go to those projects (see the OSV link in each finding).

## Supported versions

The latest release of the current major version receives fixes.
